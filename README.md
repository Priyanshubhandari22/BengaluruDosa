## 📖 About The Project

**Avighna Bengaluru Dosa** is a modern, high-performance web application designed for an authentic South Indian restaurant located around Sahastradhara Road & Mussoorie Road.

The restaurant crafts crisp dosas the traditional way: well-rested batter spread on a hot griddle, cooked to golden perfection, and served straight away with rich chutneys, aromatic sambar, and generous dollops of fresh benne (butter).

### ✨ Key Features
- **🥞 Bengaluru Benne & Classic Specials:** Detailed categorized menu (Classic Dosa, Benne Specials, Chef Specials, and accompaniments).
- **🌿 100% Pure Vegetarian:** Clear vegetarian branding and highlights.
- **📱 Direct WhatsApp Ordering:** Seamless one-click WhatsApp order flow with custom pre-filled order messages.
- **💳 Instant Scan-to-Pay:** Embedded QR code section for quick UPI/digital payments.
- **📍 Location & Directions:** Direct map navigation integration and click-to-call restaurant contact.
- **📸 Photo Gallery:** Curated gallery showcasing crispy dosas, platters, and authentic ambience.
- **⚡ Blazing Fast Performance:** Powered by TanStack Start SSR on Cloudflare's global edge network.

## 🛠️ Tech Stack

- **Framework:** [TanStack Start](https://tanstack.com/start) (Full-stack SSR with React 19)
- **Routing:** [TanStack Router](https://tanstack.com/router)
- **Server Engine:** [Nitro](https://nitro.unjs.io/) (Target: cloudflare-module)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/) & Vanilla CSS design tokens
- **Components:** [Radix UI](https://www.radix-ui.com/) & Shadcn UI
- **Icons:** [Lucide React](https://lucide.dev/)
- **Hosting / Edge Deployment:** [Cloudflare Workers & Static Assets](https://workers.cloudflare.com/)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v20+ recommended)
- [npm](https://www.npmjs.com/) or [bun](https://bun.sh/)

### Installation

1. **Clone the repository:**
   `ash
   git clone https://github.com/Priyanshubhandari22/BengaluruDosa.git
   cd BengaluruDosa
   `

2. **Install dependencies:**
   `ash
   npm install
   `

3. **Start the local development server:**
   `ash
   npm run dev
   `
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Building and Deployment

### Production Build
To create an optimized production build:
`ash
npm run build
`

### Deploy to Cloudflare
Deploy the prebuilt Nitro server bundle and static assets to Cloudflare:
`ash
npx wrangler deploy --config .output/server/wrangler.json
`
